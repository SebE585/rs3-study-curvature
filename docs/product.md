# RS3 Study Curvature

## Overview

RS3 Study Curvature is a research project that explores road geometry analysis by comparing curvature data from multiple geographic sources (OpenStreetMap, IGN BD TOPO).

This work contributes to the development of a hybrid road turn reference database and has informed the design of the RoadGenome concept used in downstream data platforms.

## Key Contributions

- **Curvature estimation pipeline** from vector road network data
- **Cross-source comparison** methodology (OSM vs. IGN)
- **Statistical analysis** of road geometry by road class
- **Visualization tools** for curvature profiles and distributions
